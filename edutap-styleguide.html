Four identities, one card.

eduTAP puts a student card on a phone. Doing that in public means borrowing the visual language of the alliance that started it, the university that hosts it, and the programme that funds it. This page holds every colour, mark and rule those four systems bring — each one with the source it came from, because they do not all carry the same weight.

Funding frame

European Union

The emblem is the one mark on this page whose use is regulated rather than recommended. Its colours also come in two flavours — the web palette from the graphics guide and the print values the Erasmus+ guidelines print.

Marks

Emblem — web palette Binding specification · Graphics guide to the European emblem

Pantone Reflex Blue and Pantone Yellow as the guide maps them for screen use.

Emblem — Erasmus+ print values Programme guidelines · Erasmus+ Visual guidelines 2021–2027, p. 8

The same emblem, converted for four-colour print. Do not mix the two sets.

EU web design system Digital design system · Europa Component Library v3.13

For EU digital products. A different blue from the emblem on purpose — it is a UI palette, not the flag. Each of these has a full tint ramp from 5 to 140.

Rules

  • The emblem is a rectangle 3:2. Twelve stars sit at the clock-hour positions on an invisible circle of radius one third of the height; each star fits a circle of one eighteenth of the height and stands on one point.
  • Never redraw, restyle or recolour the emblem, and never add the number of member states to it.
  • EU-funded work carries the emblem together with the wording Co-funded by the European Union. Both must be legible at the size used.

Programme

Erasmus+

The 2021–2027 identity is typographic: the programme name set in Roboto Medium, the EU emblem alongside it. There is no separate picture mark to place.

Marks

Primary colours Programme guidelines · Erasmus+ Visual guidelines 2021–2027, p. 8

Topic colours Programme guidelines — suggestions, not rules · Erasmus+ Visual guidelines 2021–2027, p. 8

The guidelines are explicit: no colour is attributed to a sector. Pick by topic instead — green for a sustainability project, and so on.

Four of the seven HEX values are one unit off their printed RGB triples (#007fc7 vs 0/127/200, #004a6c vs 0/75/108, #5dbfbe vs 94/191/190). Both are reproduced here as printed; the HEX is what the guidelines set in type.

Erasmus+ — Enriching lives, opening minds.

Roboto

Medium for the wordmark; Light to Black available

Roboto, Arial, sans-serif

Rules

  • Write the name in full, capital E, no space before the plus sign: Erasmus+.
  • The tagline Enriching lives, opening minds. may follow at roughly 1/23 of the name's size — 26 pt name to 11 pt tagline in the guidelines' own example. It exists in all languages; German is Neue Perspektiven, Neue Horizonte.
  • Wordmark in blue or dark blue on light grounds, white on dark grounds.
  • Outside the EC charter, Roboto is preferred and Arial is an acceptable substitute. Serif faces are ruled out.
  • Where a gradient background is used, the guidelines fix the composition — start 0 %, mix 50 %, end 100 %, or start 15 %, mix 65 %, end 100 % — while leaving the colour pair to the material.

Watch out

Where the values collide

Four places where one idea carries more than one defensible value. Each has bitten a slide deck already.

LMU has three greens in circulation

#00883ALMU-Grün, current brand guide
#009F56eduTAP Wallet pass assets
#2F854Cthe PNG this site used until August 2026

Only the first is current — it is what the brand guide specifies and what lmu.de ships. The website now uses it. The Wallet pass artwork in the shared image folder is still cut in the older #009f56 and wants re-exporting; #2f854c came from a retired PNG and should not reappear anywhere.

Two European blues, both correct

#003399emblem, web palette
#004494emblem, Erasmus+ print values

The graphics guide maps Reflex Blue to #003399 for screen; the Erasmus+ guidelines print #004494 for CMYK work. Choose one per medium and stay in it — an emblem in #004494 next to a heading in #003399 reads as a mistake.

EUGLOH's logo blue is not EUGLOH's web blue

#2B5A9Dlogo file
#115794--secondColorDark

The mark and the website were coloured independently. Keep the logo on its own value and let the surrounding interface use the web palette.

The EU's interface blue is not the emblem's blue

#003399emblem, binding
#0E47CBEU Blue 100, Europa Component Library

Searching for "the official EU blue" turns up both. The Component Library value is a UI colour for EU digital products; the emblem's is fixed by specification. Never paint the flag in #0E47CB, and do not reach for it just because it looks brighter on screen.
